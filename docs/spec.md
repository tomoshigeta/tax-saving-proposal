# 不動産投資提案書作成アプリ 仕様書 v3

> v1(ドラフト)→ v2 で未確定項目を確定し、v3(第2版アプリ)で実物件の提案書を見直した結果を反映した。
> 確定に至った経緯と却下した選択肢は `docs/decisions.md` を参照。

### v2からの主な変更(第2版)

| 項目 | v2 | v3 |
|---|---|---|
| 試算期間 | 15年固定 | **物件ごとに入力(1〜35年、既定15年)**。節税額グラフ・明細・節税効果合計が動く |
| 残債グラフ | 試算期間で打ち切り | **返済期間の全年。必ず0に着地する** |
| 年次明細 | 試算期間の行、年間節税額の列あり | **返済期間の全年。年間節税額の列は削除** |
| 登記費用 | なし | **入力項目に追加**。初年度の必要経費 |
| 「物件条件」表 | 6行 | **7行。「初期費用」(仲介手数料＋ローン事務手数料＋登記費用)を借入額の直後に追加** |
| 住所の位置 | 見出し行の右端 | **右カラムの左端(「物件条件」の左端)に揃え、物件名の下端に合わせる** |
| 2枚目 | 年次明細のみ、既定オフ | **年次明細＋「計算の根拠」(月々CFの内訳 / 価格の内訳と耐用年数)、既定オン** |

## 1. 概要

投資用不動産(キャッシュフロー・節税重視)の提案書を、物件情報の入力から自動生成するWebアプリ。
物件データを入力すると、フォーマット化された提案書(A4)を生成し、過去の提案履歴も一覧管理できる。

- **想定ユーザー**: 自分ひとり(社内ツール)。ログイン機能なし
- **利用環境**: ブラウザ。PC・タブレット
- **提案対象**: 投資用不動産。利回りではなく、キャッシュフローと節税効果を訴求する
- **設計方針**: **簡易計算を優先する。**厳密さより、入力が少なく数字がすぐ出ることを取る

### v1からの主な変更

| 項目 | v1 | v2 |
|---|---|---|
| AI読み取り(図面解析) | Claude APIで住所・画像を抽出 | **v1スコープから除外**(手動アップロード + 住所手入力) |
| 想定年収 | 入力・表示あり | **削除**。代わりに適用税率を表示 |
| 税率 | 未確定 | **所得税率をプルダウン選択(33/40/45%) + 住民税10%固定** |
| 土地分のローン利子 | 記載なし | **損益通算から除外(措法41条の4)。建物優先充当で区分** |
| 減価償却 | 建物一本 | **建物本体と設備を分離(RC造のみ)** |
| 初年度諸費用 | 記載なし | **仲介手数料・ローン事務手数料を入力。税務上の扱いを区別** |
| 空室率・家賃下落 | 「考慮しない」 | **考慮しない(家賃保証前提)。脚注で前提を明示** |
| 試算期間 | 「定年まで」(グラフ範囲は未定義) | 15年固定(→ v3 で物件ごとの入力に変更) |
| データ保存 | localStorage または IndexedDB | **IndexedDB確定 + JSONエクスポート/インポート** |

2. **物件情報入力画面**
   - 写真アップロード(1枚)

   - A4レイアウトのプレビュー

## 3. 提案書レイアウト

### 1枚目(A4・必須)

| エリア | 内容 |
|---|---|
| 見出し | 左カラムに**物件名**、右カラムに住所。住所は「物件条件」カードの左端に揃え、縦は物件名の下端に合わせる |
| 左 | 写真1枚(室内または外観)。右のカード2枚と同じ高さ。縦横比は枠に合わせて中央を切り抜く |
| 右上 | 「**物件条件**」カード。濃紺の帯 + 7行の表<br>物件価格 / 自己資金 / 借入額 / **初期費用**(仲介手数料＋ローン事務手数料＋登記費用、内訳なし) / ローン条件 / **月々のキャッシュフロー**(赤) / 適用税率 |
| 右下 | 「**N年間の節税効果 合計**」カード(淡い青地)。N は試算期間。金額を大きく右寄せ |
| 下段 | グラフ1: 年間節税額の推移(棒グラフ)<br>グラフ2: ローン残債の推移(折れ線グラフ)<br>いずれも枠付きカード、右上に単位「(万円)」 |
| 脚注 | 3行(下記) |

**配色**

| 用途 | 色 |
|---|---|
| 見出し・カードの帯・金額 | 濃紺 `#1f4e79` |
| グラフの系列(棒・折れ線とも) | 青 `#2e6da4` / 折れ線の塗り `#dce9f6` |
| マイナスのキャッシュフロー | 赤 `#d9333f` |
| 表のラベル列 | `#eff3f8` |
| 節税効果カードの地 | `#edf4fc` |

白地に対するコントラストは 見出し 8.66:1 / 系列色 5.47:1 / 赤 4.67:1。
2つのグラフはどちらも単一系列で見出しを持つため、識別を色に頼らず同じ青を使う。

**グラフの規約**
- 2軸グラフは使わない。2つのグラフを縦に積む
- グラフ1(年間節税額)の横軸: **試算期間 N 年**(1〜35)
- グラフ2(ローン残債)の横軸: **返済期間の全年**。試算期間に関わらず、必ず0に着地する。
  右上の単位表示に「返済期間 ◯年」を添える
- 目盛りは 1年・5年刻み・最終年。「定年」の点線・ラベルは表示しない

**脚注(3行)**
1. 節税額の計算式
2. 「保証賃料は契約に定める期間ごとの改定対象であり、本試算は現行の保証賃料が継続する前提です。」
3. 「所得税率◯◯% ・ 住民税10% で試算しています。」

### 2枚目(A4・任意、既定オン)

上段: 年次明細表。**行はローン返済期間の全年(完済まで)**で、試算期間には関わらない。
列: 年 / 年齢 / 賃料収入 / 減価償却費 / 支払利息 / うち土地分 / その他経費 / 不動産所得 / 通算可能な赤字 / ローン残債
(年間節税額の列は置かない。表の下に、節税効果合計が購入から N 年間の集計である旨を1行添える)

下段: 「**計算の根拠**」。左右2枠。1枚目の数字が何から出てきたかを明細のすぐ下で辿れるようにする。

| 枠 | 内容 |
|---|---|
| 左「月々のキャッシュフローの内訳」 | 縦の内訳表。保証賃料 → △ローン返済額 → △管理費・修繕積立金 → △固定資産税・都市計画税(年額÷12) → 月々のキャッシュフロー。各行の足し算が答えと一致するよう、固都税の行は差額で出す(端数処理の吸収) |
| 右「価格の内訳と耐用年数」 | 物件価格 / 土地 / 建物 / 建物本体(◯万円 x%) / 設備(◯万円 y%)。耐用年数は 法定→築年数→簡便法 の導出を建物本体・設備それぞれ1行。RC造以外では設備の行を出さない。償却基礎や年間償却費は出さない |

試算期間が長く明細が2枚目に収まらないときは、「計算の根拠」は見出しごと次ページに送る。

## 4. 入力仕様

すべて手入力。**v1ではAIによる図面・PDF読み取りは行わない。**

### 4-1. 物件

| 項目 | 必須 | 備考 |
|---|---|---|
| 物件名 | ○ | 一覧・提案書左上に表示 |
| 顧客名 | | 任意。空欄時は一覧で「物件名 + 作成日」を表示 |
| 住所 | ○ | |
| 写真 | | 室内または外観を1枚。間取り図・図面は扱わない |
| 物件価格 `P` | ○ | |
| 建物価格 `B` | ○ | `P` の内数。土地価格 `L = P − B` |
| うち設備価格 `E` | | `B` の内数。**RC造を選択したときのみ入力可** |
| 建物構造 | ○ | 下記6種 |
| 築年数 `A` | ○ | 0 = 新築 |

**建物構造と法定耐用年数**(住宅用)

| 構造 | 法定耐用年数 | 設備分離 |
|---|---|---|
| 木造・合成樹脂造 | 22年 | 不可 |
| 木骨モルタル造 | 20年 | 不可 |
| 鉄骨造(骨格材の肉厚 3mm以下) | 19年 | 不可 |
| 鉄骨造(3mm超 4mm以下) | 27年 | 不可 |
| 鉄骨造(4mm超) | 34年 | 不可 |
| RC造 | 47年 | **可** |

設備分離が不可の構造を選択している間、設備価格の入力欄は無効化する。

### 4-2. 資金

| 項目 | 必須 | 備考 |
|---|---|---|
| 自己資金 `D` | ○ | |
| ローン金利 `r` | ○ | 年率 |
| 返済期間 `N` | ○ | 年 |
| 仲介手数料 `F` | | 諸費用。**現金支出だが税務上の経費ではない** |
| ローン事務手数料 `G` | | 諸費用。**現金支出かつ初年度の必要経費** |
| 登記費用 `H` | | 諸費用(登録免許税・司法書士報酬)。**現金支出かつ初年度の必要経費**(国税庁 No.2215) |

借入額は `P − D` で自動算出(入力しない)。諸費用は自己資金とは別に手元から支出する。
不動産取得税は扱わない(入力にも計算にも含めない)。

### 4-3. 収支

| 項目 | 必須 | 備考 |
|---|---|---|
| 保証月額家賃 `Rm` | ○ | サブリースの保証賃料(月額) |
| 月額管理費・修繕積立金 `Mm` | ○ | 月額 |
| 固定資産税・都市計画税 `T` | ○ | **年額** |

いずれも全期間一定として扱う。空室率・家賃下落は考慮しない(家賃保証前提)。

### 4-4. 顧客

| 項目 | 必須 | 備考 |
|---|---|---|
| 現在年齢 | ○ | 年次明細の年齢欄にのみ使う |
| 所得税率 `t` | ○ | 33% / 40% / 45% から選択 |
| 試算期間 `N` | ○ | 1〜35年の整数。既定15年。「節税効果を合計したい年数(定年までの年数など)」 |

住民税は10%固定。復興特別所得税は考慮しない。

### 4-5. Excelからの一括入力

1件ずつ画面に打ち込むのは手間なので、Excelテンプレートに書いてまとめて取り込める。

- テンプレートは一覧画面からダウンロードする(`public/rent-assessment-template.xlsx`)
- **1行1物件**。1行目が見出し、2行目が記入例、3行目からがデータ
- 「構造」「所得税率(%)」はプルダウン。表記が違う行は取り込まず、Excel上の行番号を挙げて報告する
- 必須項目が空の行も同様に飛ばす。**取り込める行だけは取り込む**(1行の不備で全部が止まらない)
- 列は**見出し名で引く**(位置ではない)。必須列が1つでも無ければファイルごと拒否するが、
  任意列(登記費用・試算期間(年)など後から足した列)が無いファイルは受け入れ、既定値(0 / 15年)で埋める
- 金額は円単位。ローン金利は `2.5%` を `2.5` と書く
- **写真はExcelでは扱わない。**取り込んだあと入力画面で1枚だけ追加する

列定義は `src/storage/excelColumns.json` を唯一の正とし、テンプレート生成
(`scripts/make_template.py`、`npm run template`)と取り込み(`src/storage/excelImport.ts`)が
同じファイルを読む。ドメイン側との食い違いはテストで検出する。

## 5. 計算ロジック

### 5-0. 用語の区別(実装上の最重要事項)

**税務上の経費**と**現金支出**は別の概念として扱う。1つの型にまとめてはならない。

| | 税務上の経費 | 現金支出 |
|---|---|---|
| 管理費・修繕積立金 | ○ | ○ |
| 固定資産税・都市計画税 | ○ | ○ |
| ローン支払利息 | ○ | ○ |
| ローン事務手数料 | ○(初年度) | ○(初年度) |
| 登記費用 | ○(初年度) | ○(初年度) |
| **減価償却費** | **○** | **×** |
| **仲介手数料** | **×** | **○(初年度)** |
| ローン元本返済 | × | ○ |

### 5-1. 導出値

```
借入額         = P − D
初期費用       = F + G + H          (提案書「物件条件」の行。自己資金を含まない)
手元初期支出   = D + 初期費用
合計税率 τ     = t + 10%
土地価格 L     = P − B
```

### 5-2. 耐用年数

```
法定耐用年数 U = 構造から決定(4-1の表)

新築 (A = 0):
  耐用年数 = U

中古 (A > 0):
  A >= U  →  U × 0.2
  A <  U  →  (U − A) + A × 0.2

月数で計算し、年未満を切り捨て。下限2年。
```

設備の耐用年数は、**`U = 15` に上記と同じ式を独立に適用**する(建物本体とは別に計算)。

### 5-3. 減価償却

償却方法は**定額法**(建物・建物附属設備とも法令上これ以外の選択肢がない)。

```
仲介手数料の建物分 Fb = F × B / P

本体償却基礎 = (B − E) + Fb × (B − E) / B
設備償却基礎 = E + Fb × E / B

年間減価償却費 = 本体償却基礎 / 耐用年数     (耐用年数を過ぎた年は 0)
               + 設備償却基礎 / 設備耐用年数 (同上)
```

初年度も月割せず、満1年分を計上する。

### 5-4. ローン

元利均等返済。

```
月利 i = r / 12
回数 n = N × 12
月々返済額 = 借入額 × i(1+i)^n / ((1+i)^n − 1)
```

各年について、支払利息の年合計と年末残債を算出する。

### 5-5. 土地に対応する借入金(損益通算の除外)

租税特別措置法41条の4により、不動産所得の赤字のうち土地を取得するための負債利子に相当する部分は損益通算できない。

区分は**建物優先充当**(措置法施行令26条の6第2項)による。負債はまず建物の取得の対価に充てられ、次に土地に充てられたものとして計算する。

```
土地対応借入   = max(0, 借入額 − B)     ※ B は契約上の対価(仲介手数料を加算しない)
土地対応割合 α = 土地対応借入 / 借入額
土地対応利子   = その年の支払利息 × α
```

### 5-6. 月々キャッシュフロー

```
月々CF = Rm − Mm − 月々返済額 − T / 12
```

全期間一定。

### 5-7. 年間の不動産所得と節税額

```
賃料収入   = Rm × 12
経費       = Mm × 12 + T + 年間減価償却費 + 支払利息 + (初年度のみ G + H)
不動産所得 = 賃料収入 − 経費

通算可能な赤字 = max(0, −不動産所得 − 土地対応利子)
年間節税額     = 通算可能な赤字 × τ
```

不動産所得が黒字の年の節税額は 0 とする(マイナス表示・増税の表示はしない)。

### 5-8. 集計とグラフ範囲

```
試算期間     = N年(入力。1〜35、既定15)
節税効果合計 = Σ 年間節税額  (N年分)
```

**試算期間は物件ごとの入力。**顧客が「あと何年働くか」に合わせて決める(決定記録 D10d)。
年ごとの数字は N に依存しないので、N=3 の合計は N=15 の先頭3年の合計と一致する。
既定の15年で読み込めば、固定だった頃の提案書の数字は変わらない。

年次明細と残債グラフは N に関わらず**返済期間の全年**(完済まで)を出す(D22・D23)。
N が返済期間より長い場合、N 年目までの年間節税額は集計に入るが、明細には返済期間分しか載らない。

### 5-9. 端数処理

- 金額は円未満切り捨て
- 耐用年数は月数で計算し、年未満切り捨て、下限2年

## 6. データ保存

- **IndexedDB** に保存する。localStorage は使わない(画像をbase64化すると容量上限に達するため)
- サーバー側DBなし、ログインなし
- 保存内容: 入力データ一式 / 写真(Blob) / 生成日時 / 更新日時
- 写真はアップロード時にクライアント側で長辺1600pxにリサイズし、JPEGに変換して保存する
- **JSONエクスポート/インポート**を備える(ブラウザのキャッシュクリア・PC買い替えへの対応)

## 7. 出力

- HTML表示 → ブラウザの印刷機能でPDF化
- A4 1枚目は必須、2枚目(年次明細表＋計算の根拠)は表示のオン/オフを切り替え可能(既定オン)
- 印刷用CSS(`@media print`)でページ分割を制御する
